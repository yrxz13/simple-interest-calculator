# Simple Interest Calculator

A command-line calculator that computes simple interest from a principal amount, an annual interest rate, and a time period.

## Usage

Run the script with Bash:

```bash
bash simple-interest.sh
```

Enter the principal amount, the annual interest rate as a percentage, and the time period in years. For example, enter `1000`, `5`, and `2` to calculate interest of `100.00`.

The calculator uses the formula **Simple interest = (Principal × Annual rate × Time) / 100**. The result is in the same currency as the principal.
